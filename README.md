## Portfolio — Run locally

Requires a Node.js version compatible with the Astro version declared in `package.json`.

```bash
npm ci
npm run dev
```

Open `http://localhost:4321`.

To check a production build:

```bash
npm run build
npm run preview
```

The static site is generated in `dist/`.

## Project structure

```text
src/
  data/profile.ts       # Portfolio content and links
  pages/index.astro     # Main page
  layouts/              # Page layouts
  styles/global.css     # Visual styles
public/                 # Public assets
astro.config.mjs        # Astro configuration
```
